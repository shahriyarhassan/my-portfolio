Relay control with green and red lamps

Automation Studio · Sequence 1

Sequence of Operation

  • The relay activates when the NO push button is pressed.
  • When the relay is ON, the green lamp turns on.
  • When the relay is OFF, the red lamp turns on.

Latching circuit with NO and NC push buttons

Automation Studio · Sequence 2

Sequence of Operation

  • When the NO push button is pressed, the indicator lamp turns on and stays on after the button is released (latching).
  • The lamp turns off when the NC push button is pressed.

Jog and latching control with a selector switch

Automation Studio · Sequence 3

Two push buttons (Start and Stop) and one selector switch.

Sequence of Operation

  • When the Start push button is pressed with the selector switch in position 0, the indicator lamp turns on without latching (jog mode).
  • When the Start push button is pressed with the selector switch in position 1, the indicator lamp turns on and latches.
  • The lamp turns off when the NC Stop push button is pressed.

Two start and two stop buttons for one load

Automation Studio · Sequence 4

Two Start push buttons and two Stop push buttons control a single load.

Sequence of Operation

  • Pressing any one of the Start push buttons turns the load on (latching).
  • Pressing any one of the Stop push buttons turns the load off.

Interlocked lamps with a common stop button

Automation Studio · Sequence 5

Sequence of Operation

  • Pressing push button 1 turns lamp 1 on. Push button 3 turns it off.
  • Pressing push button 2 turns lamp 2 on. Push button 3 turns it off.
  • If lamp 1 is started first, lamp 2 cannot be turned on at the same time.
  • If lamp 2 is started first, lamp 1 cannot be turned on at the same time.

Lamp changeover with a common stop button

Automation Studio · Sequence 6

Sequence of Operation

  • Pressing push button 1 turns lamp 1 on. Push button 3 turns it off.
  • Pressing push button 2 turns lamp 2 on. Push button 3 turns it off.
  • Only one lamp can run at a time.
  • If lamp 1 is on and push button 2 is pressed, lamp 2 turns on and lamp 1 turns off immediately.
  • The same logic applies to both lamps.

Sequential relay start and reverse stop

Automation Studio · Sequence 7

Sequence of Operation

  • Pressing NO push button 1 turns relay 1 on.
  • Pressing NO push button 2 turns relay 2 on.
  • Pressing NO push button 3 turns relay 3 on.
  • The starting sequence is 1, 2, 3 and the stopping sequence is 3, 2, 1.

Dependent relays with automatic cut-off

Automation Studio · Sequence 8

Sequence of Operation

  • Pressing the NO push button turns relay 1 on.
  • When relay 1 turns on, relay 2 turns on at the same time.
  • If relay 2 does not turn on after relay 1 is activated, relay 1 turns off immediately.
  • A stop switch is available for both relays.
